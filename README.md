# zdo website

Public app information, privacy policy, and support pages for zdo, in English and Finnish.

- Website: https://sanluh.github.io/zdo-website/
- Privacy policy: https://sanluh.github.io/zdo-website/privacy.html
- Support: https://sanluh.github.io/zdo-website/support.html

## Editing and publishing

Edit the HTML files and shared `styles.css`, then commit and push to `main`.
GitHub Pages publishes from the repository root on `main`. No dependencies or build step.
Finnish pages have a `-fi.html` suffix. Keep both languages in sync.

Preview with `python3 -m http.server 8080` from this folder.

Only website files belong here; the native app is maintained separately.
Add an App Store link when a public listing is available. Support address: `zdo.support@icloud.com`.
